# Frontend do projeto Águias

## O que é o frontend?

O frontend é a parte visual do site: é o que os visitantes veem no navegador. Ele mostra a vitrine de produtos, blog, galeria, carrinho e o painel administrativo.

## Páginas existentes

- **Início**: mostra categorias e produtos em destaque.
- **Galeria**: apresenta fotos e trabalhos visuais.
- **Sobre**: texto institucional sobre a empresa.
- **Blog**: lista de artigos publicados.
- **Cursos**: página para listar cursos ou serviços.
- **Contato**: formulário para enviar mensagens ao time.
- **Carrinho**: área onde o cliente escolhe produtos e finaliza com Pix ou WhatsApp.
- **Painel Admin**: área restrita para o administrador gerenciar conteúdo.

## Como acessar o painel administrativo

- Abra o endereço `/admin/login` no navegador enquanto o frontend estiver rodando.
- Será necessário login com usuário e senha do administrador.
- Depois de logado, você terá acesso ao menu de gerência.

## O que você consegue editar no painel

- **Produtos**: criar, editar ou excluir produtos, incluindo preço, estoque e imagens.
- **Blog**: publicar e editar posts com texto rico (editor WYSIWYG).
- **Galeria**: enviar novas imagens e remover imagens antigas.
- **Feedbacks**: aprovar ou reprovar mensagens de clientes.
- **Mensagens**: consultar mensagens recebidas pelo formulário de contato.
- **Configurações**: atualizar número do WhatsApp e dados do Pix usados no site.

## Como o cliente final usa o site

- Pode navegar pelos produtos e categorias.
- Pode ver detalhes de cada produto e gerar código Pix.
- Pode enviar pedidos pelo WhatsApp através do carrinho.
- O admin usa o painel para manter tudo atualizado.

> Este README não mostra como instalar nada. Ele explica somente o que cada parte do site faz e onde o administrador pode atuar.
